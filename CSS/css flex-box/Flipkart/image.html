HTML Basic Tags

  • <html> — Root of the page
  • <head> — Meta info and styles
  • <body> — Visible content
  • <h1> to <h6> — Headings
  • <p> — Paragraph
  • <img> — Image with alt tag
  • <a> — Hyperlink
  • <ul> / <li> — List items

Tag Use Example
